# فونت‌ها / Fonts

سایت فقط از فونت‌های مجاز شما (لیست Fontpoly) استفاده می‌کند و فایل فونت به‌صورت
خودمیزبان (self-hosted) لود می‌شود — هیچ درخواستی به Google Fonts یا سرویس بیرونی نمی‌رود.

## فایل‌های موردنیاز (خانواده‌ی پیش‌فرض: یکان بخ ۳)

فایل‌هایی که از ربات تلگرام Fontpolybot دریافت می‌کنید را با همین نام‌ها در همین پوشه بگذارید:

| نام فایل | وزن |
|---|---|
| `YekanBakh3-Regular.woff2` (یا `.ttf`) | ۴۰۰ |
| `YekanBakh3-Medium.woff2` (یا `.ttf`) | ۵۰۰ |

- هر دو فرمت woff2 و ttf پشتیبانی می‌شوند؛ اگر فقط ttf دارید، همان را با نام بالا بگذارید.
- تا وقتی فایل‌ها اینجا نباشند، صفحه با فونت پیش‌فرض سیستم (Segoe UI / …) نمایش داده می‌شود.

## تغییر خانواده‌ی فونت

اگر فونت دیگری از لیست (مثلاً ایران سنس ایکس، ماهور، کهربا، …) را می‌خواهید:

1. فایل‌های آن فونت را با نام دلخواه (مثلاً `IranSansX-Regular.woff2`) اینجا بگذارید.
2. در `assets/css/styles.css` بلاک‌های `@font-face` را کپی کنید و نام فایل/خانواده را عوض کنید.
3. متغیر `--font` را به نام خانواده‌ی جدید تنظیم کنید.

## نکته‌ی مجوز / License

فونت‌های لیست Fontpoly عمدتاً تجاری هستند (فروشگاه‌هایی مثل فونت‌ایران و نون‌فونت).
برای انتشار عمومی یک سایت تجاری، مجوز «وب‌سایت / وب‌فونت» همان فونت را تهیه کنید؛
فایل‌های این پوشه را در مخزن گیت‌هاب عمومی نگذارید مگر اینکه مجوز توزیع داشته باشید
(پوشه در `.gitignore` قرار ندارد؛ قبل از `git add` مراقب باشید).
